# Outputs of running example dataset evaluation

1,200 training and 600 test sequences sampled from `human_enhancers_ensembl` in [Genomic Benchmarks](https://github.com/ML-Bioinfo-CEITEC/genomic_benchmarks). Their lengths run from 4 to 568 nt, so the per-position checks reach position 483 while only positions 1-359 are compared - and 1-359 is what the per-position figures draw. A little real train-test leakage survives into the split report.

## evaluate-classes

Compare sequence characteristics between train and test sets. Files are pooled and classes inferred from the label column.

```bash
gb-qc evaluate-classes \
  --input examples/enhancers/data/enhancers_train.csv \
  --input examples/enhancers/data/enhancers_test.csv \
  --out-folder example_outputs/enhancers_dataset
```

Running the above command for `gb-qc evaluate-classes` tool will create `example_outputs/enhancers_dataset` folder with the following results:

```text
class/
└── sequence/
    └── 0_vs_1/
        ├── gb-qc-report.csv
        ├── gb-qc-report.html
        └── plots/
```

- `gb-qc-report.csv` - simple report with the results (pass/warning/fail) of the evaluation between two classes of the dataset.
- `gb-qc-report.html` - visual report with the results of the evaluation between two classes of the dataset. It contains basic information about the dataset and plots visualizing individual features of the dataset.
- `plots/` - plots used in `html` report are also stored in this folder in `png` format

The `sequence` directory is named after the sequence column, and `0_vs_1` after the two compared classes.

Simple and html reports are generated by default. You can change types of generated reports with `--report-types` argument. Supported values are `simple`, `html` and `json`. Json report contains dump of all computed statistics about dataset, written per class to `class/sequence/per-class/<class>.json`.

The report is published on the [example reports site](https://genomic-benchmarks.github.io/genomic-benchmarks-qc/), so you can read it in the browser without downloading anything:

- `class/sequence/0_vs_1/gb-qc-report.html`: <https://genomic-benchmarks.github.io/genomic-benchmarks-qc/example_outputs/enhancers_dataset/class/sequence/0_vs_1/gb-qc-report.html>

## evaluate-splits

Detect train-test data leakage via sequence similarity.

```bash
gb-qc evaluate-splits \
  --train-input examples/enhancers/data/enhancers_train.csv \
  --test-input examples/enhancers/data/enhancers_test.csv \
  --sequence-column sequence \
  --out-folder example_outputs/enhancers_dataset
```

Running the above command for `gb-qc evaluate-splits` tool will create `example_outputs/enhancers_dataset` folder with the following results:

```text
split/
└── sequence/
    └── enhancers_train_vs_enhancers_test/
        ├── gb-qc-report.csv
        ├── gb-qc-report.html
        ├── plots/
        └── mmseqs/
```

- `gb-qc-report.csv` - a simple report if data leakage check passed or failed.
- `gb-qc-report.html` - report with clusters containing sequences from both train and test dataset parts, that could indicate data leakage.
- `plots/` - similarity distribution plots used in the `html` report, in `png` format.
- `mmseqs/` - raw MMseqs2 search results and the FASTA files of the sequences involved in hits.

The `sequence` directory is named after the searched sequence column, matching the layout of `evaluate-classes`, and `enhancers_train_vs_enhancers_test` after the two input files. Temporary MMseqs2 files are written inside the comparison directory and removed unless `--keep-tmp-files` is given, so several comparisons of one dataset can run concurrently against the same `--out-folder`.

Simple and html reports are generated by default. You can change types of generated reports with `--report-types` argument. Supported values are `simple`, `html` and `json`. Json report contains dump of all train-test mixed clusters.

The report is published on the [example reports site](https://genomic-benchmarks.github.io/genomic-benchmarks-qc/), so you can read it in the browser without downloading anything:

- `split/sequence/enhancers_train_vs_enhancers_test/gb-qc-report.html`: <https://genomic-benchmarks.github.io/genomic-benchmarks-qc/example_outputs/enhancers_dataset/split/sequence/enhancers_train_vs_enhancers_test/gb-qc-report.html>
