Data Leakage

GenBenchQC evaluate-splits uses MMseqs2 to perform an ultra fast and sensitive test sequence search against a train set database and compute alignment-based metrics for detecting data leakage across train–test splits.

Data leakage is defined as the percentage of sequences in the test/train set that have exceeded a set similarity threshold. Similarity is defined as the alignment coverage factored by the percentage identity. Coverage is the fraction of the test (query) and train (target) sequences covered by the alignment, and percentage identity is the proportion of identical aligned positions in the aligned region.
