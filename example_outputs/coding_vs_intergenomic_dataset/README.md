# Outputs of running example dataset evaluation

600 coding and 600 intergenomic sequences of 200 nt, sampled from `demo_coding_vs_intergenomic_seqs` in [Genomic Benchmarks](https://github.com/ML-Bioinfo-CEITEC/genomic_benchmarks). The two classes differ in composition strongly enough that most per-sequence checks fail, which is what makes this a useful thing to look at.

```bash
gb-qc evaluate-classes \
  --input examples/fasta-classes/data/coding_seqs.fasta \
  --input examples/fasta-classes/data/intergenomic_seqs.fasta \
  --out-folder example_outputs/coding_vs_intergenomic_dataset
```

Running the above command for `gb-qc evaluate-classes` tool will create `example_outputs/coding_vs_intergenomic_dataset` folder with the following results:

```text
class/
└── sequence/
    └── coding_seqs_vs_intergenomic_seqs/
        ├── gb-qc-report.csv
        ├── gb-qc-report.html
        └── plots/
```

- `gb-qc-report.csv` - simple report with the results (pass/warning/fail) of the evaluation between two classes of the dataset.
- `gb-qc-report.html` - visual report with the results of the evaluation between two classes of the dataset. It contains basic information about the dataset and plots visualizing individual features of the dataset.
- `plots/` - plots used in `html` report are also stored in this folder in `png` format

Each class is named after its input file, lowercased and reduced to characters that are safe in a path, and classes are ordered alphabetically whatever order the files were given in — so `coding_seqs.fasta` and `intergenomic_seqs.fasta` give the directory `coding_seqs_vs_intergenomic_seqs`. The class names shown inside the reports keep their original form.

FASTA inputs have no sequence column, but the reports still sit under a `sequence` directory so that the layout is identical for every input format.

Simple and html reports are generated by default. You can change types of generated reports with `--report-types` argument. Supported values are `simple`, `html` and `json`. Json report contains dump of all computed statistics about dataset, written per class to `class/sequence/per-class/<class>.json`.

The report is published on the [example reports site](https://genomic-benchmarks.github.io/genomic-benchmarks-qc/), so you can read it in the browser without downloading anything:

- `class/sequence/coding_seqs_vs_intergenomic_seqs/gb-qc-report.html`: <https://genomic-benchmarks.github.io/genomic-benchmarks-qc/example_outputs/coding_vs_intergenomic_dataset/class/sequence/coding_seqs_vs_intergenomic_seqs/gb-qc-report.html>
